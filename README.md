# hiv_circuit_sim — Model v1.2.1

Anyone can clone this repository, install the environment, and regenerate every figure from version-controlled Python — not from a notebook that hides the ODEs.

The scientific question is **not** “what numbers make the circuit win?” It is **what numbers the circuit would require to work**, compared with documented biology.

This is an **effective-compartment** within-host model of early HIV infection (cells and virions per mL). It is not an anatomically resolved human body.

## Reproduce

```text
pip install -r requirements.txt
pytest
python scripts/run_campaign.py
```

Figures land in `results/figures/`. Run manifests (parameter hash, solver, seed, scenario) land in `results/raw/<run_id>/`.

Optional larger sensitivity run:

```text
python scripts/run_sensitivity.py --n 10000
```

The manuscript reports the reproducible **N = 128** eight-parameter LHS/PRCC global screening analysis generated by the campaign. Larger-N runs are optional robustness extensions and are not reported as completed manuscript results. Do not retune Class A biology because a figure looks ugly — see `parameters/CHANGELOG.md`.

## What is frozen

| File | Role |
| --- | --- |
| `parameters/parameter_registry.csv` | Every parameter: class, DOI/PMID, range, whether it may be swept |
| `parameters/baseline_v1.csv` | Locked Class A + exploratory Class B midpoints (identical snapshot of the registry at freeze) |
| `parameters/sensitivity_ranges_v1.csv` | LHS bounds |
| `parameters/success_criteria_v1.yaml` | Pre-registered success / partial / fail |
| `docs/PROTOCOL.md` | Run hierarchy, negative-result policy |
| `data/literature/SOURCES.md` | What was actually read vs what is a mapping |

**Engineered parameters have source = none.** They are never given fake citations.

`beta` is **derived** from Ribeiro et al. 2010 median R0 = 8 together with frozen `T0, p, c, delta_I`. It is not fitted to make the circuit look good.

## Model v1.2.1 states (17 core + 3 delay-chain = 20 total states)

`T_E, T_U` engineered vs unmodified targets (explicit `f_E`); eclipse `E5, E4`; productive `I5, I4`; virus `V5, V4`; surface/internal CCR5 and CXCR4; dimensionless `A5, A4, B, C5, C4`; delay chain `Q1–Q3` for `tau_B`.

Infection uses saturating receptor maps `F(R) = R^h / (K^h + R^h)` (Platt et al. 1998: infection is **not** linear in CCR5). Receptor trafficking splits internalization, recycling, synthesis, and degradation.

Equations: `docs/MODEL_V1_EQUATIONS.md`.

## Literature anchors (Class A)

- HIV T–I–V structure: Perelson & Ribeiro 2013, PMID 24020860
- `d_T = 0.01 /day`, `T0 = 10^6 /mL`: Mainou et al. 2024, DOI 10.1371/journal.pcbi.1012129
- `c ≈ 23 /day` (9.1–36): Ramratnam et al. 1999, PMID 10577640
- Typical sim `δ = 0.7`, `p = 4000` with that `c`: Ikeda et al. 2014, PMID 24885827
- Eclipse ~1 day / generation 2.6 day: Perelson et al. 1996, PMID 8599114
- Acute R0 median 8: Ribeiro et al. 2010, PMID 20357090
- CCR5 density on CD4 T cells: Reynes et al. 2000, PMID 10720514
- Nonlinear infectability vs CCR5: Platt et al. 1998, PMID 9525605
- CXCR4 1%/min constitutive; SDF-1 ~50% down in 5 min: Signoret et al. 1997, PMID 9348282
- CCR5 protein t½ 6–9 h: Signoret et al. 2000, PMID 11121442

Mappings (Hill `K`, some recycling half-times, CCR5 ligand `k_int`) are labeled as mappings in the registry. They are not pretended to be tabulated constants.

## Philosophy

Human/experimental data determine replication and trafficking timescales. Simulation **discovers** required `A` half-life, `T_A`, `tau_B`, suppressor strength, and `f_E`. Poor regions are kept (`docs/PROTOCOL.md` negative-result policy).

## Release packaging

`python package_release.py` creates `hiv_circuit_sim_v1.2.1_release.zip`, containing the source code, frozen configs/parameters, tests, documentation, and the canonical regenerated `results/` used by the manuscript. Runtime caches and compiled Python artifacts are excluded.

## Layout

```text
hiv_circuit_sim/
  src/            # the model (not the notebook)
  parameters/     # provenance
  configs/        # run intents
  scripts/        # CLI
  tests/          # fail-closed sanity
  data/literature/
  results/figures/
```

The YAML files in `configs/` are human-readable run-intent snapshots. Regression tests verify that their baseline values remain aligned with the executable scenario factory.
